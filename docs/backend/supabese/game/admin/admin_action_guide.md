# Admin Action Guide for `rooms.admin_action`

این سند توضیح می‌دهد که ستون JSONB با نام `admin_action` در جدول `rooms` چگونه برای مدیریت اضطراری روم‌های Normal و Tournament استفاده می‌شود.

---

## 🎛 هدف ستون `admin_action`
این ستون یک کنترل‌کنندهٔ انعطاف‌پذیر برای ادمین است تا بتواند:

- روم را **لغو (Cancel)** کند
- زمان شروع روم را **تغییر (Reschedule)** دهد
- روم را **موقتاً متوقف (Freeze)** کند
- یا دستور قبلی را **پاک (Clear)** کند

این دستورات تنها زمانی اعمال می‌شوند که روم در حالت `waiting` باشد و توسط تابع `fn_manage_waiting_rooms()` پردازش خواهند شد.

---

## 🟥 1) لغو روم (Cancel)
برای متوقف کردن فوری یک روم:

```
update public.rooms
set admin_action = '{"action":"cancel"}'
where id = 'ROOM_ID';
```

**نتیجه:** روم به حالت `canceled` می‌رود و دیگر هیچ پردازشی روی آن انجام نمی‌شود.

---

## 🟧 2) تغییر زمان شروع (Reschedule)
برای تغییر ساعت شروع روم (عموماً برای Tournament):

```
update public.rooms
set admin_action = '{"action":"reschedule","new_time":"18:45"}'
where id = 'ROOM_ID';
```

**نتیجه:** مقدار `starts_at` به ساعت جدید امروز تنظیم می‌شود و `admin_action` پس از اعمال پاک خواهد شد.

---

## 🟦 3) توقف موقت (Freeze)
برای زمانی که باید روم در حالت انتظار بماند و هیچ اتفاقی برایش نیفتد:

```
update public.rooms
set admin_action = '{"action":"freeze"}'
where id = 'ROOM_ID';
```

**نتیجه:** روم شروع نمی‌شود، ریست نمی‌شود و در حالت انتظار می‌ماند.

---

## 🟩 4) پاک کردن فرمان (Unfreeze / Clear)
برای بازگشتن به رفتار عادی:

```
update public.rooms
set admin_action = '{}'::jsonb
where id = 'ROOM_ID';
```

**نتیجه:** روم دوباره توسط سیستم عادی مدیریت خواهد شد.

---

## 📝 رفتار سیستم برای انواع روم‌ها
### 🔵 Normal Rooms
- اگر به حد نصاب برسد → **شروع می‌شود**
- اگر نرسد → **تایمر ریست می‌شود**
- اگر freeze باشد → هیچ کاری انجام نمی‌شود
- اگر cancel باشد → مستقیم به `canceled` می‌رود

### 🔴 Tournament Rooms
- فقط بر اساس زمان شروع (`starts_at`) فعال می‌شود
- حد نصاب مهم نیست
- reschedule ساعت جدید را اعمال می‌کند
- freeze آن را معلق نگه می‌دارد
- cancel آن را حذف می‌کند

---

## ✨ خلاصه
ستون `admin_action` یک مکانیزم منعطف و ساده برای کنترل اضطراری روم‌هاست. با سه فرمان ساده ادمین می‌تواند:

- روم را **لغو** کند
- **زمان جدید** بدهد
- **فریز/متوقف** کند
- یا کنترل را به سیستم برگرداند

بدون نیاز به تغییر ساختار دیتابیس یا منطق اصلی بازی.
